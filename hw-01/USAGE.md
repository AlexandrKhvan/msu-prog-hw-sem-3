# Домашнее задание №1 (hw-01)

Реализация базовых утилит `mycp` и `myfind`.

---

## 1. Структура

```text
hw-01/
├── Makefile       # Сценарий сборки и запуска тестов
├── USAGE.md       # Инструкция по проекту
├── inc/           # Заголовочные файлы
│   ├── mycp.h
│   └── myfind.h
└── src/           # Исходный код реализации и тестов
    ├── mycp.c
    ├── myfind.c
    └── main.c     # Юнит-тесты (assert-проверки)
```

## 2. Сборка и тестирование

### Сборка:

Сборка осуществляется компилятором gcc по стандарту C11 с включенными строгими флагами предупреждений (-Wall -Wextra -Werror -O2 -std=c11 -Iinc).

```bash

make test

```


### Тесты: 

1) Тест создания и побайтового копирования файла через mycp, а также проверка обработки ошибки несуществующего файла.

2) Тест поиска совпадений по подстрокам, отсутствующих слов и несуществующих путей через myfind.
