## Регламент сдачи и проверки (Workflow)

1. **Ветки.** Каждое домашнее задание выполняется в отдельной ветке вида `hw-<номер>_<название или тема>`, например `hw-01`, `hw-02_pipe_n`.
2. **Сдача.** Для сдачи создается Pull Request из ветки задания в ветку `main`.
3. **Ревью.** Преподаватель назначается в качестве Reviewer. Замечания исправляются дополнительными коммитами в ту же ветку.
4. **Мердж.** После аппрува (Approved) PR сливается в `main`.
