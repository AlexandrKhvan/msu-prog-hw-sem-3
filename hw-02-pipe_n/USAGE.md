## Запуск: просто выполнить что-то вроде:

```bash
gcc -Wall -Wextra -Werror -O2 -std=c23 pipe_n.c -o pipe_n

./pipe_n
```

## Пояснение:

### execute_pipeline():

Функция в цикле порождает процессы через `fork()`, связывая их через неименованные каналы `pipe()`: в каждом дочернем процессе вызов `dup2()` перенаправляет стандартный ввод на чтение из канала предыдущей команды, а стандартный вывод (если конечно команда не последняя) - в запись следующего канала. После этого неиспользуемые дескрипторы закрываются, и запускается утилита через `execvp()`. В это время родительский процесс закрывает уже отработавшие дескрипторы, передает конец для чтения на следующую итерацию, а после создания всей цепочки дожидается завершения каждого дочернего процесса с помощью `waitpid()`

### Тесты:

Тестирование построено с помощью функции capture_pipeline_output, которая перехватывает STDOUT конвейера в строковый буфер и проверяет его содержимое через assert.

1) test_single_command (базовый случай, N=1):

    - echo: проверка вывода обычной строки с переводом строки.

    - printf: проверка корректности передачи многострочного текста.

    - expr 20 + 22: проверка выполнения арифметической утилиты и возврата строки "42\n".

    - echo -n: проверка передачи данных без завершающего символа \n.

2) test_two_commands (связка из двух звеньев, N=2):

    - echo | tr: трансляция регистра символов из нижнего в верхний.

    - printf | sort: лексикографическая сортировка переданных строк.

    - printf | grep: фильтрация строк по регулярному выражению (^ap).

    - echo | cut: разбиение строки по разделителю (:) и извлечение первого поля.

    - printf | head -n 1: взятие первой строки из потока.

3) test_multi_stage_pipeline (сложные цепочки, N≥3):

    - printf | grep -v | sort (3 команды): фильтрация с инверсией и последующая сортировка.

    - printf | sort -k2,2n | cut | tr (4 команды): сортировка по второму числовому столбцу, извлечение первого поля и перевод в верхний регистр.

    - printf | sort | uniq -c | grep | tr (5 команд): подсчет уникальных вхождений строки и проверка наличия "3 foo".

    - cat /etc/passwd | cut | sort | tr | head -n 5 (5 команд): проверка, что конвейер из условия лабы не пустой, возвращает ровно 5 строк (\n), а символы приведены к верхнему регистру/валидным символам имени пользователя.
